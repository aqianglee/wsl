## 2. 重寫原則

1. **加回第一人稱**：開頭直接說「為什麼我寫這個」。
2. **砍章節**：14 節 → 8 節左右。FAQ 從 5 題砍到 3 題；「致致謝」併成一行；「明確不做」改成一段口語。
3. **表格只留兩個**：功能對照表（資訊密度高，留）和系統需求（短，留）。其餘表格改回散文。
4. **徽章砍到 2 個**：只留 License 和 Platform。版本、Python 版本這種讀者不在乎的拿掉。
5. **句子改短、改掉對仗**：允許不完整句、允許「其實」「就」「而已」這種口語。
6. **英文段改名** `English TL;DR` → `English`，內容從 bullet 改成一段話。
7. **保留所有事實**：指令、路徑、版本號、135 項測試、restic 下載機制——一個字不改錯。
8. 長度：從約 320 行壓到 **150–180 行**。

## 3. 改寫前後對照（節選）

### 3.1 開頭

**改前（現版）**

> \# WSL Deck
>
> \> Windows 桌面 GUI，把 `wsl.exe` 的常用操作可視化，用來管理多個 WSL2 發行版實例。
>
> [6 個徽章]
>
> ## 這是什麼
>
> **WSL Deck** 是一款跑在 Windows 上的輕量桌面應用，把分散在命令列的 `wsl.exe` 操作包成一個可視化介面：
>
> - 想用 GUI 看所有 WSL 實例的狀態、IP、磁碟大小？
> - 想一鍵啟停、開終端、開資料夾，而不是背指令？
> - 想要**增量快照**、**備份／還原／複製**，而不是每次重灌？
> - 想統一管理 **Windows → WSL 的端口轉發與防火牆規則**？
>
> 這些事，`wsl.exe` 都能做，但要分好幾條指令、好幾個工具。WSL Deck 把它們收進同一個視窗。

**改後（預覽）**

> \# WSL Deck
>
> 管理 WSL2 實例的 Windows 桌面程式。
>
> [License 徽章] [Platform 徽章]
>
> WSL 實例裝多了之後，哪台跑什麼、IP 多少、磁碟吃了多少，全得開 PowerShell 敲指令查。我受夠了，所以寫了這個：打開就是一頁卡片（或表格），每台實例的狀態、IP、容量都在上面，啟停、開終端、備份、做快照都是按一下的事。

### 3.2 「為什麼做這個」整節

**改前**：獨立一節，5 條 bullet 對照指令，結尾一句官腔總結。

**改後**：不單獨成節，併進開頭第二段，兩三句帶過——

> 底層就是 `wsl.exe`、`netsh` 和 restic，沒有魔法。指令你本來就能自己敲，這裡只是把它們排在同一個視窗裡。快照是官方沒有的功能，用 restic 做增量備份，密碼檔存在本機。

### 3.3 「明確不做的事」

**改前**：4 條工整 bullet，每條粗體開頭。

**改後**：一段隨性的話——

> 有幾件事刻意不做：Docker Desktop 那兩個系統實例只看不碰（弄壞了 Docker 自己負責）；還原是「先備份再整台蓋掉」，不做 diff；SSH 和檔案傳輸不內建，反正 `wt.exe` 和檔案總管都開得到。還有，只支援 Windows——程式裡全是 `netsh` 和註冊表，搬到別的平台沒意義。

### 3.4 FAQ

**改前**：5 題，每題粗體 Q＋完整段落 A。

**改後**：3 題，口語問答——

> **視窗沒出現？** 如果你是用 AI 工具或 CI 啟動的，子行程會被回收。直接雙擊 exe 或用 `pythonw main.py`。
>
> **docker-desktop 為什麼不能動？** 那是 Docker 自己的東西，弄壞了重灌 Docker 的是你，所以鎖起來。
>
> **改網路規則跳 UAC？** `netsh` 需要管理員。會把變更湊成一批，一次授權跑完。

### 3.5 英文段

**改前**：`## English TL;DR`＋5 條 bullet。

**改後**：`## English`＋一段 4–5 句的話，結尾順口說 issue/PR 中英文都行。
